# Onboarding: New Corp Joining Synergy of Steel

Welcome to SYN! To make the start as smooth as possible, here are the key steps for the CEO and the corp.

## 1. For the CEO — Administrative First Steps

1. Fully verify your main character on the [Alliance Auth Portal](https://auth.synergyofsteel.de/) (as well as [WinCo Auth](https://auth.wintercoalition.space/) / [SeAT](https://seat.winterco.org/)). Verify all further characters (alts) afterwards via [CharLink](https://auth.synergyofsteel.de/charlink/) — CharLink automatically ensures that all characters are registered in the relevant modules (e.g. Corp Statistics, Structures, Moon Mining).
2. Make sure all members are entered fully and correctly in the Character Audit Tool.

## 2. Rulebook & Communication

* Read the alliance's full [rulebook](rules.md) carefully — it covers fleet obligations, taxes, the code of conduct, and recruiting, among other things.
* To see the language-specific Discord channels (Alliance Announcements, Orga News, Talk Channel), every pilot must join the **lang_german** and/or **lang_english** group.

## 3. Tools & Contacts

* **Grafana** (https://grafana.synergyofsteel.de/) is used for improved visualization of the Auth databases. The following standard dashboards are available to all Corp Leaders:
    * *01 Onboarding* — checks whether all tokens are up to date
    * *02 Fleet Analyse* — shows the corp's adjusted FAT values (last 3 months + current month, duplicates removed)
    * *03 Billing* — overview of the corp's tax/billing status

    To view these dashboards, the CEO must first log in to Grafana — only then can they be properly assigned. If corp members should also get access to these dashboards, this is only possible on the CEO's request; the request goes to Ruby.
* For questions, concerns, or conflicts, the Alliance Diplomats are available, via ticket or Discord DM.
* Rulebooks for reference:
    * [SYN Rulebook](https://docs.google.com/document/d/1WBoXUsBM3KoqQGvcQoANCHr3xl-F-bkkNhvdwNBlmws/edit?usp=sharing)
    * [Coalition Rulebook](https://docs.google.com/document/d/1nQ0ZIlcmGFn-LnIdwXh9bQY4c4nf-Eds3x94jb-o5xI/edit?usp=drivesdk)

If anything is unclear, the escalation chain applies: first your own Corp Leadership, then the Alliance Diplomats, and finally the Alliance Leadership.
